# Blog Reading System 2026-05

目标：把每日博客从“复杂前端展示页”收敛成“内容优先、Markdown 风、好阅读、好跳转”的投资笔记系统。

## 原则

1. 首页负责发现与跳转，不承载正文复杂模块。
2. 文章页负责深度阅读，优先 Markdown 语义：标题、段落、列表、表格、引用、来源。
3. CSS 只服务可读性：行宽、行高、标题层级、引用块、表格和移动端节奏。
4. JS 只服务导航：时间线、卡片居中、预览抽屉、键盘与 ESC。
5. 事实、来源、创作者输入、我的判断必须分层，不能为了“像专业”编造。

## 首页 / 归档入口

- 使用时间线归档替代默认日历格子。
- 月份锚点定位到该月第一篇文章。
- 横向卡片预览，当前卡片自动居中。
- 点击非当前卡片：先居中。
- 点击当前卡片：打开轻量预览抽屉。
- 抽屉只放摘要、日期、关键词和“阅读全文”，不承载完整正文。
- 传统日历保留在折叠区作为兼容视图。

## 文章页模板

文章正文应尽量接近：

```markdown
# 标题

> 一句话核心结论

## 1. 今天最重要的判断
## 2. 发生了什么
## 3. 为什么重要
## 4. 对持仓 / 观察池的影响
## 5. 风险与反证
## 6. 下一步观察
## 7. 来源与证据边界
```

每日投资文章最低要求：

- 一句话结论
- 事实层
- 来源层
- 我的判断
- 动作边界
- 风险与反证
- 下一步观察

## 样式边界

保留：

- 阅读型 hero
- 目录 / 快速跳转
- 重点引用块
- 简洁表格
- 来源区
- 上一篇 / 下一篇

弱化或禁止：

- 大量嵌套小卡片
- dashboard 迷宫
- 复杂渐变与过度动画
- 为每个 section 单独设计组件
- 把观察列表写成交易动作
